# 净搜 CleanSearch

搜索引擎去广告净化脚本（Tampermonkey / Violentmonkey / Greasemonkey）。屏蔽百度 / 谷歌 / 必应 / 360 搜索以及知乎 / B站 / 豆瓣 / 微博 / CSDN 等常见中文社区的搜索与页面广告。另带「护航模式」：搜「XX 官方下载」这类词时，把官网标绿置顶、把聚合下载站标黄提醒，找不到官网时在结果顶部给一条警告。

## 安装与使用

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Edge / Chrome / Firefox 均支持）。
2. 安装脚本，二选一：
   - GitHub Raw：<https://github.com/vetshiuan/cleansearch/raw/main/cleansearch.user.js>
   - [GreasyFork 一键安装](https://greasyfork.org/zh-CN/scripts/594115)
3. 装好后打开百度 / 必应搜一个商业词（如「英语培训」），广告条应消失。

设置入口在油猴菜单里：**净搜 · 设置**（总开关、10 个站点开关、功能开关、屏蔽关键词 / 屏蔽网址 / 白名单、配置导入导出），旁边还有「立即重新净化」。调试用的控制台接口是 `window.__CleanSearch`，暴露 `{ version, openPanel, runAll, runGuardian, cfg, probe }`，F12 可直接调。旧版「【屏蔽广告】」脚本（GreasyFork 460743）的屏蔽词表会自动迁移一次。

## 去广告与护航怎么判断

广告识别按下面的顺序走，命中即移除最近的结果级容器：

1. **页面结构属性**：`data-tuiguang`、`data-module="ad"`、`data-placeid`、`cmatchid`。
2. **广告类名**：`ec-tuiguang`、`ecom-result`、`cos-pc-ad-container` 等广告专用类。
3. **广告 / 推广角标**：识别「广告 / 推广 / 商业推广 / Sponsored」等角标，兼容纯文本、图标 + 文字混排、CSS 伪元素渲染三种形态。
4. **自定义屏蔽词 / 网址**：用户设的关键词（匹配标题 / 摘要）与网址片段。

判定都在结果容器内进行，正常结果的类名（百度 `c-container`、必应 `b_algo`）只用来定位、不删除；右栏「相关搜索」等正常栏目默认保留（可在设置里关）。

护航模式的判定以真实域名为准，域名优先于标题文案：正文里出现下载站域名不会把官网误判成下载站；反过来，「标题蹭品牌词 + 陌生域名 + 诱导下载」的仿冒站会被识别并黄标警示。百科 / 资讯页既不在官网库也不带品牌诱导词，不会被误伤。

## 隐私与已知限制

- 纯本地：所有配置存在浏览器油猴本地存储（`GM_setValue`），不经过任何服务器，无统计、无上报。
- 唯一的对外请求：开启「网址屏蔽」且结果是百度跳转链接（`baidu.com/link?url=...`）时，会向百度直连解析出真实地址用于屏蔽判定；结果只存在本页会话内存里，不落盘、不外发。
- 搜索引擎（尤其百度）会不定期改版 DOM，某天若出现漏删，先打开设置检查开关，或到 Issue 反馈搜索词与页面截图。
