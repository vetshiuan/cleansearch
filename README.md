# 净搜 CleanSearch

> 搜索引擎去广告净化脚本（Tampermonkey / Violentmonkey / Greasemonkey 油猴脚本）
> 只做一件事：**去广告、去竞价排名**。不做重定向、不做美化、不掺推广。

净搜专注屏蔽**搜索引擎的竞价排名广告与推广内容**，覆盖百度 / 谷歌 / 必应 / 360 搜索，以及知乎、B站、豆瓣、微博、CSDN、百度系子站（贴吧 / 文库 / 百科 / 知道）等中文站点的常见广告位。内置零依赖设置面板，无任何第三方推广与暗桩。

## 🔍 广告判定原理（透明公开）

广告识别按优先级执行，命中即移除最近的结果级容器：

1. **结构化属性**：`data-tuiguang`、`data-module="ad"`、`data-placeid`、`cmatchid`
2. **广告专用类名**：`ec-tuiguang`、`ecom-result`、`cos-pc-ad-container` 等
3. **角标文本**：识别"广告 / 推广 / 商业推广 / Sponsored"等角标——兼容纯文本、**图标+文字混排**、**CSS 伪元素渲染**三种形态
4. **自定义规则**：用户屏蔽的关键词（标题/摘要）与网址片段

判定全程在结果容器内进行，正常结果的类名（如百度 `c-container`、必应 `b_algo`）只作定位不作删除；右栏"相关搜索"等正常栏目默认保留（可开关）。

## 🔒 隐私

- 脚本**不向任何第三方发送数据**，无统计、无上报
- 唯一的网络请求：百度搜索结果的跳转链接解析（`baidu.com/link?url=...` → 真实地址，用于网址屏蔽判定），仅在你启用了"网址屏蔽"且结果为百度跳转链时发生，请求直达百度，结果仅存于本页面会话内存
- 所有配置存储在浏览器油猴本地存储（`GM_setValue`），不经过任何服务器

## ⚠️ 已知限制

- 搜索引擎（尤其百度）会不定期改版 DOM，若某天出现漏删，请打开设置检查开关，或到 Issue 反馈搜索词与页面截图
- 360 搜索、豆瓣、微博的广告容器未经大规模实测，规则以保守为主
